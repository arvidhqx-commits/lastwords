# LastWords
Custom death messages for Paper 1.21+/26.x (runtime-tested on Paper 1.21.11, 26.2 and 26.3 — 45 assertions against the shipped jar). Random message pools per death cause (PvP, fall, lava, void, explosion…), MiniMessage colors and gradients, {killer}/{weapon}/coordinates placeholders, private death-coordinates message. Drop-in: edit one YAML, `/lastwords` to reload. No dependencies.
